## Recommendations for v1.3 milestone scope

When `/gsd-new-milestone` runs, consider these as anchor candidates:

**If v1.3 is a "partner-onboarding-ready" milestone (recommended):**
- All Tier 1 items (admin password rotation, privacy policy confirmation) — MANDATORY
- Tier 2: color-contrast measurement (bundled with color refresh below) + Neon branch split + post-deploy DB-smoke CI
- Tier 3: UI color refresh + partner home dashboard restructure + MetricTiles + /proposals route + inline Loyer estimé chip

**If v1.3 is a "feature-expansion" milestone:**
- Skip the gates (defer to v1.4), focus on Tier 5 items: Excel export, webhook notifications, centralized LC reference dashboard

**If v1.3 is an "infrastructure" milestone:**
- Tier 2 in full + Better Auth hardening + Playwright tests + Sentry observability + audit-log viewer

The 2-3 Tier-1 items should NOT be deferred past v1.3 — they're partner-onboarding blockers.
