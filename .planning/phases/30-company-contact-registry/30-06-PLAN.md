<objective>
Ship `/clients` — the partner-facing client book (CRM-07) and the create-client dialog that feeds
it (CRM-01). This is the first real-app adoption of the ReUI DataGrid table machinery and the
resolution of the long-open "cursor vs page-index" architecture question: adopt
`DataGrid`/`DataGridTable`/`DataGridColumnHeader`, reject `DataGridPagination`, `Filters` and row
selection.

Purpose: CRM-07 is the partner's entry point into the registry, and it is the surface where a
cross-tenant leak would be most visible. Every affordance that could reveal another partner's data
— a global row count, a page-index footer, an autocomplete, a filter builder — is deliberately
absent, not merely hidden.

Output: a server-rendered page, a DataGrid-backed client grid with cursor pagination and
server-side sort, and a two-field creation dialog.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL search params → server query | `q`, `sort`, `dir`, `cursor` and anything else the user appends |
| rendered list metadata → partner | counts, cursors and sort affordances that could reveal out-of-scope rows |
| create-client keystrokes → server | a typing surface that could become an existence oracle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-06-01 | Elevation of Privilege | forged owner scope via search param | mitigate | `ownerId` is read from `session.user.id` only; a test asserts an injected `?ownerId=`/`?user_id=` param never reaches `listClientBook`, and a grep gate forbids reading those params (CRM-02) |
| T-30-06-02 | Information Disclosure | inference via row/page totals | mitigate | `DataGridPagination` is not adopted and `recordCount` is the current page length; no total, no page count and no "N results" text is rendered anywhere |
| T-30-06-03 | Information Disclosure | search acting as an existence oracle | mitigate | The zero-results state is the fixed generic string `clients.empty.search.title`, identical whether a global record exists or not; the server query is owner-scoped, so a match outside the scope is never even fetched |
| T-30-06-04 | Information Disclosure | autocomplete/typeahead on company name or SIREN | mitigate | Assumption A-5 enforced structurally: no datalist, combobox, debounce-fetch or async lookup in `CreateClientDialog`; grep-gated |
| T-30-06-05 | Elevation of Privilege | adopting `solution-crm-3`'s ownership model | mitigate | Row selection and the bulk owner-assignment bar are omitted from the column list entirely — not hidden, not disabled; grep-gated against `DataGridTableRowSelect`/`RowSelectAll` |
| T-30-06-06 | Tampering | forged cursor or sort value | mitigate | `sort`/`dir` are enum-validated server-side with a silent fallback; a malformed cursor is ignored by `decodeCursor` (plan 30-04) and can at worst re-window the caller's own scope |
| T-30-06-07 | Information Disclosure | client-side re-sort of a partial page | mitigate | `manualSorting: true`; sorting pushes to the URL and deletes `cursor`, so appended pages arrive already ordered. Grep-gated against a local `.sort(` over `rows` |
| T-30-06-08 | Elevation of Privilege | admin reaching the partner surface | mitigate | `requireRelationshipHolder()` calls `notFound()` for admins; admins use the `requireAdmin()`-gated `/[adminSegment]/companies` tree instead |
| T-30-06-SC | Tampering | npm/pip/cargo installs | mitigate | No new registry fetch and no package install — every primitive used is already vendored under `src/components/ui/` or `src/components/reui/` and carries the `source-safety view passed — 2026-08-31` verdict from `docs/design/reui-blocks-audit.md` |
</threat_model>
