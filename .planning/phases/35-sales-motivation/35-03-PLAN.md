<decision_record>
**`movements` is passed as one `WeeklyMovements` object, not as a bare array
plus a separate count.** `35-UI-SPEC.md`'s props block lists
`movements: MomentumRow[]`, but the truncation line needs the full window total,
and a second `movementsTotal` prop can drift out of sync with the capped rows it
describes. The spec's own note says the JSX block is "illustrative structure,
not a literal file to paste"; this keeps the two values in the single object the
query already returns. No copy, layout or behaviour changes.

**`nowMs` is NOT a prop on `MomentumCard`.** The spec lists it mirroring
`RelanceCard`, but `RelanceCard` needs it (its `statusLabel` computes overdue-ness
at render). `MomentumCard` derives nothing from the current instant: the streak,
the window and the tracked-since fragment are all computed server-side before
the component is reached. An unused prop would be an unused binding, and CI runs
`eslint . --max-warnings=0`, so it would fail the build rather than merely read
oddly. The discipline the prop signals is preserved — the page still reads the
clock ONCE via its existing `getNowMs()` helper and passes derived values down.

**`trackedSinceLabel` is the month-year FRAGMENT ("septembre 2026"), not a
sentence.** The component assembles the sentence with
`t('dashboard.momentum.trackedSince', lang).replace('{0}', trackedSinceLabel)`.
This resolves the one internal ambiguity in `35-UI-SPEC.md` (its JSX skeleton
renders the prop bare while its i18n key plan declares `{0}`); the key plan wins,
because a bare fragment is not a sentence in either language.

**Movement row layout.** The row keeps `RelanceCard`'s two-column split
(company name left, detail right) because the Typography table says movement
rows match it "exactly". The copy contract's single sentence is preserved as the
link's `aria-label`, so the accessible name is the full sentence while the
visual layout is the established one.

**"Cette semaine" section label.** `35-UI-SPEC.md`'s Typography table has no row
for it. It renders `text-xs font-semibold text-muted-foreground` — 12px at a
sanctioned weight, sentence case, because the spec reserves UPPERCASE for the
card's own eyebrow title only. Recorded rather than silently chosen.
</decision_record>
