## Environment notes for whoever picks this up

- `npm run build` cannot run locally: `.env.production.local` outranks `.env.local`, so any
  NODE_ENV=production command resolves DATABASE_URL to the Neon **main** (production) branch
  and the prebuild guard hard-fails by design. Do not work around it. Local gates are
  `npx tsc --noEmit`, `npm run lint:check`, `npx vitest run`. Build coverage comes from CI.
- Never run the backfill in apply mode locally, and never run `npm run db:migrate` locally.
- `grep` in the agent shell is a ugrep wrapper: `grep -qv` cannot prove absence and
  `grep -c` exits 1 on zero matches. Do not build an acceptance check on those forms alone.
