Method note: screencast frames alone are a SAMPLE and cannot prove absence of a
sub-frame flash (the weakness D-38-03 names). The decisive evidence is the causal
ordering below, taken from the same trace: the inline no-flash script COMPLETES
before the first Paint event, so the light SSR markup is overwritten before the
compositor ever runs. A light frame is not merely unobserved, it is impossible.

SSR HTML actually shipped, by cookie state (curl against the same server):
  no lt_theme cookie : data-theme="light"   <- flip required before paint
  lt_theme=system    : data-theme="light"   <- flip required before paint
  lt_theme=dark      : data-theme="dark"    <- no flip needed
