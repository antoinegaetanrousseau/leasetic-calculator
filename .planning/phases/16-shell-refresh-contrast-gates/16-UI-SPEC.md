## Component Contracts

### `<PageHero>` — NEW (D-01..D-05)

**File:** `src/components/ui/PageHero.tsx`
**Directive:** server component (no `'use client'`)
**Pattern:** inline `style={{}}` — matches existing server-component primitives (`<MetricTile>`, `<AdminNavCard>`, `<StatusChip>`)

**Props interface (locked, D-01):**
```ts
export interface PageHeroProps {
  title: string;          // Required. The greeting or page title.
  subtitle?: string;      // Optional. Muted description line below title.
  eyebrow?: string;       // Optional. Uppercase label above title (e.g. "ADMIN", "ÉTAPE 1 SUR 3").
  actions?: React.ReactNode; // Optional. Right-aligned CTA slot.
  children?: React.ReactNode; // Reserved; not consumed in Phase 16.
}
```

**Layout (D-03):**
- Outer: `display: flex`, `justifyContent: 'space-between'`, `alignItems: 'flex-start'`, `marginBottom: 32` (D-04).
- Left column: stacked `eyebrow` (if present) → `title` → `subtitle` (if present). Column direction: `display: flex`, `flexDirection: 'column'`.
- Right slot: `actions` node, top-aligned. When `actions` is absent, left column expands naturally (no explicit `flex: 1` needed; right slot does not render).

**Eyebrow (D-02):**
- `fontSize: '11.8px'`, `fontWeight: 700`, `letterSpacing: '0.06em'`, `textTransform: 'uppercase'`, `color: 'var(--gd)'`, `marginBottom: 8`.

**Title (D-02):**
- `fontSize: 32`, `fontWeight: 700`, `lineHeight: 1.2`, `color: 'var(--ink)'`, `margin: 0`.

**Subtitle (D-02):**
- `fontSize: '14.5px'`, `fontWeight: 400`, `lineHeight: 1.55`, `color: 'var(--muted)'`, `marginTop: 8`.

**Dark mode:** `<PageHero>` uses only `--ink`, `--muted`, `--gd` tokens. These tokens automatically resolve to dark values via `html[data-theme="dark"]` cascade. No per-component dark CSS needed. (D-05)

**No `className` escape hatch** — per Claude's Discretion in CONTEXT.md; pages needing a custom hero render inline JSX instead.

**Test file:** `src/components/ui/PageHero.test.tsx`
Test cases (must all pass):
1. Renders `title` only (minimal props)
2. Renders `title` + `subtitle` — subtitle visible
3. Renders `title` + `subtitle` + `eyebrow` — eyebrow is uppercase, color `var(--gd)`
4. Renders `title` + `actions` — actions slot is present on right side
5. Renders all 4 props together — full layout
6. Light snapshot (no `data-theme` on wrapper)
7. Dark snapshot (`data-theme="dark"` on wrapper element)

## Contrast Audit Contract (CONTRAST-01, CONTRAST-02)

**Sign-off artifact:** `docs/accessibility/16-contrast-audit.md` (directory `docs/accessibility/` does not yet exist — create it)

**Method:** Manual measurement via WebAIM Contrast Checker (https://webaim.org/resources/contrastchecker/). Document effective foreground and background hex after alpha blending.

**Required composites (D-09) for CONTRAST-01:**

| # | Composite | FG | BG | Mode |
|---|-----------|----|----|------|
| 1 | Diff-panel changed-row text | `--ink` weight 600 (`#41423d`) | `rgba(224,133,48,0.10)` over `--surface` (`#ffffff`) → blended `#fff1e1` | Light |
| 2 | Diff-panel changed-row text | `--ink` weight 600 (`#41423d`) | `rgba(224,133,48,0.10)` over `--paper` (`#f5f7fc`) → blended `#fdf1e4` | Light |
| 3 | Diff-panel changed-row text | `--ink` dark (`#e6e9ef`) | `rgba(224,133,48,0.10)` over `--surface` dark (`#161e2d`) → blended `#1d2033` | Dark |
| 4 | `.chip-invited` StatusChip text | chip text color (planner reads `StatusChip.tsx` to confirm) | `--gold` tint bg (planner reads chip bg value) | Light |
| 5 | `.chip-invited` StatusChip text | chip text color | `--gold` tint bg | Dark |

**Required composites (D-10) for CONTRAST-02 (Phase 16 new surfaces):**

| # | Composite | FG | BG | Mode |
|---|-----------|----|----|------|
| 6 | `<PageHero>` eyebrow | `--gd` (`#129657`) | `--paper` (`#f5f7fc`) | Light |
| 7 | `<PageHero>` eyebrow | `--gd` (`#129657`) | `--paper` dark (`#0c121c`) | Dark |

CONTRAST-02 note: if the planner introduces any additional `--gold` or `--teal` foreground-on-background pair during Phase 16 implementation (e.g. in the footer or sidebar refresh), those must be added as rows 8+ in the audit table.

**Pass threshold:** ≥4.5:1 for normal text (WCAG 2.1 AA).

**Alpha-blending formula for pre-calculation:**
For `rgba(224,133,48,0.10)` over `#ffffff`:
- R: `255 × (1 − 0.10) + 224 × 0.10 = 252.1 → 252`
- G: `255 × 0.90 + 133 × 0.10 = 242.8 → 243`
- B: `255 × 0.90 + 48 × 0.10 = 234.3 → 234`
- Blended: `#fcf3ea` (planner should verify with DevTools computed value)
