Purpose: DOC-10, DOC-11, DOC-12, DOC-13 and FIELD-03 are gates on the finished output rather than

Output: a Phase 43 layout proof suite, a reconciled Phase 41 typography proof, and a regenerated

**Order matters.** Regeneration is the LAST step. If a proof written in Task 2 forces a corrective
edit to `document.tsx`, the regeneration must happen after that edit, or the committed baseline
records a document that no longer exists. `src/lib/pdf/document.tsx` is in `files_modified` for
corrective edits only — this plan does not add layout.

**D-16's precision.** ROADMAP criterion 5 and DOC-13 both say "byte-identical", but
`src/lib/pdf/render.ts:16-34` documents that the raw `sha256` is NOT stable across renders:
@react-pdf/renderer's Fiber scheduler orders PDF objects differently on each call. `contentHash`
(sorted, inflated stream hashes) is the deterministic contract and is what the fixture file stores.
**Do not write a test asserting raw `sha256` equality between two renders.** It will fail for reasons
unrelated to this phase.
</objective>
