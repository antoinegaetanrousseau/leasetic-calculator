`npm run lint:check` green at every wave boundary.

**Phase-wide deletion rule — read this before writing any deletion into any Phase 43 plan.**
`t()` is strictly typed: `DictKey = keyof typeof dictionaries.fr` and
`function t(key: DictKey, lang: Lang): string` (`src/lib/i18n/dictionaries.ts:2576-2587`). Removing
a key from the object literal removes it from the `DictKey` union, so a surviving `t('that.key', …)`
call is a **compile error**, not an inert runtime lookup. The same applies to the `DictKey[]`-typed
`phase8Keys` and `twoArgKeys` arrays in `dictionaries.test.ts`, and — via
`eslint --max-warnings=0` — to orphaned style tokens and components.

Therefore: **every deletion in Phase 43, whether of a dictionary key, a style token or a component,
lands in the same plan that removes its last consumer — never in an earlier wave.** `npm run
typecheck` is a distinct required CI step from `npm run lint:check`; both must exit 0 at every wave
boundary. The one accepted red interval in this phase is the `__pdf-fixtures__` hash drift, which
every affected plan declares explicitly in its own `<verification>`.
