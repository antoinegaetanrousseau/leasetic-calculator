## Two scope facts the executor must not discover the hard way

**1. There are TWO hydration sites, not one.** The verification report names only
`parametres/page.tsx:108`. `app/(authed)/proposals/new/_actions/saveAndAdvance.action.ts:77` runs
the same fallback on every step-1 save:
`partnerCo: u.companyName?.trim() || (nextInputs.partnerCo as string | undefined)?.trim() || nameFallback,`.
Fixing only the page leaves the action re-injecting the person's name on the very next save. This
is the same two-call-site shape D-12 already warned about in this phase.

**2. Dropping the fallback WILL break the wizard unless `partnerCo` becomes optional.**
`src/lib/calc/schema.ts:177` is `partnerCo: z.string().min(1, ...)`. Both hydration sites' own
comments say the fallback exists "so that partnerCo always satisfies min(1)", and
`app/(authed)/aide/commencer-ici/page.tsx:18-26` documents the real incident this prevented:
"The `seed-partner-launch.ts` script does not set `users.companyName`, which makes `partnerCo`
empty in the session-derived hydration on wizard step 1, which in turn makes
`proposalInputSchema.safeParse` fail on step 2. Both Antoine and Delphine hit this gate."

An em dash cannot render for a value the schema forbids from being empty. And `companyName` is
admin-set (required on the partner-creation form, `src/lib/admin/schemas.ts:90`) and NOT
partner-editable — so blocking a partner on it would violate 43-CONTEXT.md D-13's standing rule:
"A partner must never be blocked from finalizing by an admin-side setting they cannot fill in."
Making `partnerCo` optional is therefore part of option (a), not scope creep.

`src/lib/wizard/completedSteps.ts` is deliberately NOT in `files_modified`: its `STEP_1_KEYS` list
is a D-21 change-detection list, not a required-field list, and `partnerCo` belongs in it.

**Byte-determinism sequencing.** `render-fixtures.test.ts` and `commission-free-fixture.test.ts`
remain EXPECTED RED from 43-09 and 43-10. Do **NOT** run `npm run pdf:update-fixture` —
regeneration happens exactly once, in 43-12.
