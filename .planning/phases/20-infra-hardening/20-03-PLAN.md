    1. Go to https://vercel.com/<your-team-slug>/leasetic-matrice/settings/environment-variables

      keeps history), then debug; do NOT proceed to Step 5

    ### Step 5: Update Vercel env vars — PREVIEW scope

    Repeat Step 3 selecting "Preview" scope and pasting the `preview` branch's
    pooled connection string.

    ### Step 6: Verify PREVIEW scope

    - Open a draft PR or visit a recent preview deployment
    - Smoke check: log in, view `/proposals`, confirm no DB errors

    ### Step 7: Update Vercel env vars — PRODUCTION scope LAST (D-02)

    Repeat Step 3 selecting "Production" scope and pasting the `main` branch's
    pooled connection string. (Production was already on `main` implicitly;
    you are now explicitly pinning rather than relying on the default.)

    - Visit https://leasetic-matrice.vercel.app → log in → smoke check the
      `/coefficients` page (sanity — read-heavy admin surface)
    - Run: curl -s https://leasetic-matrice.vercel.app/healthz | jq .
    - Expected: { "db": "ok", "blob": "ok" }

    ### Step 9: Provision GitHub Environment secrets for plan 20-02's db-migrate.yml

    1. Go to GitHub repo Settings → Environments → `production` → Environment secrets
    2. Add `DATABASE_URL_PREVIEW` = pooled connection string of the `preview` branch
    3. Add `DATABASE_URL_DEVELOPMENT` = pooled connection string of the `development` branch
    4. Rename the existing `DATABASE_URL_PROD` secret to `DATABASE_URL_MAIN`
       (or add `DATABASE_URL_MAIN` with the same value alongside the legacy
       `DATABASE_URL_PROD` during a transition; 20-02's workflow only reads
       `DATABASE_URL_MAIN`)
