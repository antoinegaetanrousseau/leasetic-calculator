## Breadcrumb Trail Table (exact shape for 31.1-03 to consume)

`RouteMeta.breadcrumb: BreadcrumbSegment[]` where `interface BreadcrumbSegment { labelKey: DictKey; href?: string }`. The array is never empty, never exceeds 2 elements, and the **last** element never has `href` (render as `BreadcrumbPage`); any earlier element **always** has `href` (render as `BreadcrumbLink`).

| Route (pathname) | Trail |
|---|---|
| `/` | `[{ labelKey: 'header.home' }]` |
| `/proposals` | `[{ labelKey: 'sidebar.nav.proposals' }]` |
| `/proposals/{id}` | `[{ labelKey: 'sidebar.nav.proposals', href: '/proposals' }, { labelKey: 'shell.breadcrumb.proposalDetail' }]` |
| `/proposals/` (trailing slash, no id) | `[{ labelKey: 'sidebar.nav.proposals' }]` — no phantom detail segment |
| `/proposals/new` (+ any wizard sub-step) | `[{ labelKey: 'sidebar.nav.proposals', href: '/proposals' }, { labelKey: 'header.proposals.new' }]` |
| `/clients` | `[{ labelKey: 'sidebar.nav.clients' }]` |
| `/clients/{id}` | `[{ labelKey: 'sidebar.nav.clients', href: '/clients' }, { labelKey: 'shell.breadcrumb.clientDetail' }]` |
| `/clients/` (trailing slash, no id) | `[{ labelKey: 'sidebar.nav.clients' }]` — no phantom detail segment |
| `/aide` (+ any sub-path) | `[{ labelKey: 'sidebar.nav.help' }]` |
| unmatched partner path | `[{ labelKey: 'header.home' }]` (fallback) |
| `/{adminSegment}` (admin home) | `[{ labelKey: 'sidebar.nav.home' }]` |
| `/{adminSegment}/coefficients` | `[{ labelKey: 'sidebar.nav.adminCoefficients' }]` |
| `/{adminSegment}/partners` | `[{ labelKey: 'sidebar.nav.adminPartners' }]` |
| `/{adminSegment}/partners/new` | `[{ labelKey: 'sidebar.nav.adminPartners', href: '/{adminSegment}/partners' }, { labelKey: 'admin.partners.breadcrumb.new' }]` |
| `/{adminSegment}/companies` | `[{ labelKey: 'sidebar.nav.adminCompanies' }]` |
| `/{adminSegment}/companies/{id}` | `[{ labelKey: 'sidebar.nav.adminCompanies', href: '/{adminSegment}/companies' }, { labelKey: 'shell.breadcrumb.companyDetail' }]` |
| `/{adminSegment}/companies/review` | `[{ labelKey: 'sidebar.nav.adminCompanies', href: '/{adminSegment}/companies' }, { labelKey: 'sidebar.nav.adminReconciliation' }]` |
| `/{adminSegment}/history` | `[{ labelKey: 'sidebar.nav.adminHistory' }]` |
