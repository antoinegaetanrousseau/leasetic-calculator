## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Reworded TopbarBreadcrumb.tsx's docblock to avoid tripping Task 2's own dangling-reference grep gate**
- **Found during:** Task 2
- **Issue:** Task 1's docblock for `TopbarBreadcrumb.tsx` referenced the file it replaces by name ("replaces the former `TopbarTitle`", "for exactly the same reason `TopbarTitle` did"). Task 2's acceptance criterion is a literal `grep -rn "TopbarTitle" app src` returning nothing — after deleting `TopbarTitle.tsx`, those two doc-comment mentions would still match and falsely report a dangling reference, exactly the self-tripping-gate trap the tooling_warning calls out.
- **Fix:** Reworded both sentences to describe the predecessor by role ("the topbar's former page-title island", "its predecessor") instead of by name. No functional change.
- **Files modified:** `src/components/TopbarBreadcrumb.tsx`
- **Verification:** `grep -rn "TopbarTitle" app src` → no output (exit 1) after the file was deleted and the docblock was reworded.
- **Committed in:** `1a5b916` (Task 2 commit — the docblock fix and the deletion landed together since the deletion is what exposed the trap)

**2. [Rule 1 - Bug] Fixed a false assertion in the "1-segment route, no separator" test case**
- **Found during:** Task 3
- **Issue:** First draft asserted `screen.queryAllByRole('link')` has length 0 on a 1-segment breadcrumb. `BreadcrumbPage` (the primitive's own default, unmodified) sets `role="link"` on its `<span>` alongside `aria-disabled="true"` — so the non-link current-page span itself matches an `getAllByRole('link')` query, and the assertion failed even though the actual behavior (no anchor, no separator) was correct.
- **Fix:** Reworked the assertion to check for real `<a>` elements (`currentPage.closest('nav')?.querySelectorAll('a')` has length 0) and no separator (`[data-slot="breadcrumb-separator"]` has length 0), plus `currentPage.tagName !== 'A'` — testing the actual DOM shape instead of the ARIA role, which the primitive intentionally overloads for its "non-navigable but link-styled" current-page semantics.
- **Files modified:** `src/components/Topbar.test.tsx`
- **Verification:** `npx vitest run src/components/Topbar.test.tsx` — 8/8 passing.
- **Committed in:** `8ff4b13` (Task 3 commit — caught before the first commit of this task, so no separate fix-up commit)
