## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request → server component | searchParams (`?archived=1`, `?q=...`) crosses untrusted |
| Server component → buildListResponse | userId derived from session (trusted); archived from query (untrusted but bounded boolean) |
| buildListResponse → DB query | userId MUST scope every branch (defense against IDOR) |
| createDraft → unique index | concurrent draft creation races on lc_ref allocation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01-01 | Information disclosure (IDOR) | buildListResponse archived branch | mitigate | SQL filter `WHERE user_id = $userId` MUST be present in archived branch (Test 4 enforces); query params (`?archived=1`) never trusted as a userId override |
| T-17-01-02 | Information disclosure (soft-delete leak) | archived 30-day window | mitigate | SQL `deleted_at >= NOW() - INTERVAL '30 days'` AND `user_id = $userId` combined — never trust query for user override; Phase 10 purge cron handles eventual hard deletion |
| T-17-01-03 | Tampering (lc_ref collision) | createDraft concurrent allocation | mitigate | Partial unique index `proposals_user_id_lc_ref_uq WHERE lc_ref IS NOT NULL` (Phase 12 D-05) is the backstop; sequential allocator wraps in a transaction with retry-on-unique-violation up to 3 attempts (D-04 accepts gaps from abandoned drafts) |
| T-17-01-04 | Repudiation (lifecycle event omission) | createDraft no audit_log | accept | Per Phase 13 D-16, pre-finalize events do not write to audit_log; lcRef pre-allocation is a backend implementation detail (CONTEXT Established Patterns); ASVS L1 audit scope unchanged |
| T-17-01-05 | Information disclosure (commission via SQL) | listProposalsByUser projection | mitigate | ProposalRowDto projection (list.ts:8-24) strips commission_pct from the output by construction; ADMIN-09 9-gate suite verifies no leakage; this plan changes filter, not projection |
| T-17-01-06 | Denial of service (unbounded archived scan) | archived candidate-set scan | accept | userId scope + 30-day window + cursor pagination cap; v1.3 partner volume is small (<1000 rows/partner expected); future v1.4+ may add a covering index if measured |
