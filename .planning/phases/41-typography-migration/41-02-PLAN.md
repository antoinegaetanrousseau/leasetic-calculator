| Boundary | Description |
|----------|-------------|
| upstream GitHub release → repository | Font binaries enter the repo from an external source and become the PROP-17 byte-determinism baseline. Untrusted until hash-verified. |
| repository → rendered PDF | `Font.register` reads `public/fonts/*.ttf` at render time via absolute `file://` paths in the Node runtime. A changed, renamed or missing binary changes or breaks every delivered document. |
| `public/fonts/` → public web | Next copies `public/` verbatim into the standalone build; the TTFs are fetchable at `/fonts/Inter-400.ttf`. |
