## Overview

v1.4 introduced a `partner_type` dimension (Agent / Commercial / Partenaire) that conditions
proposal economics end-to-end — a business-approved exception to the otherwise-frozen formula:
Agent/Commercial proposals drop the commission factor entirely, with commission structurally
absent (not hidden) from every UI surface, the PDF, server logs, and audit payloads. It also
shipped a session-only Admin/Agent view toggle for admins, fixed PDF number/typography rendering
(U+202F glyph overlap) and removed the Destinataire block, and closed admin-home label changes
plus a status-pill sizing fix. The teal rebrand (BRAND-01/02/03) was descoped mid-milestone as
too much effort for too little value and shelved to Future Requirements.

## v1.4 Cross-Cutting Invariants

These were constraints every v1.4 phase had to satisfy.

### 1. ADMIN-09 commission invisibility — reinforced and extended (PTYPE-05 / PTYPE-07)

For `Agent`/`Commercial` partner types, commission is **fully absent** from calc output, UI
surfaces, PDF render path, server logs, and audit payloads — structurally absent, not
conditionally hidden. The grep-contract suite (`tests/admin-09-grep-contracts.test.ts`) grew
from 13 → 19 gates (Phase 22). The Phase 13 D-12 partner-facing relaxation (`Partenaire` deal
owner sees commission on wizard steps 2+3) continues to hold for `Partenaire` only.

### 2. `params_snapshot` PDF immutability (PTYPE-06)

The snapshot schema was extended to record `partner_type` + `commission_applied` so PDFs remain
reproducible after a partner's type changes. Stored proposals + rendered PDFs stay permanently
frozen.

### 3. Light + dark pair per design change (BRAND-01 / BRAND-03)

Standing policy: any visual change ships light + dark simultaneously, each recolored pair ≥4.5:1
WCAG 2.1 AA. *(The teal token swap this invariant originally anticipated was descoped 2026-05-30
— no token churn shipped in v1.4.)*

### 4. PDF byte-determinism CI gate (PDF-03)

Phase 23 regenerated the SHA-256 fixture after the layout change (Destinataire removal +
typography fix); Phase 22's commission-free variant extended the golden corpus. Gate stayed green.

### 5. Frozen formula + tranche boundaries

The `Partenaire` formula (`loyer = montant HT × (1 + commission/100) × coefficient / 100`) and
all tranche boundaries stayed frozen. The only approved exception: Agent/Commercial drop the
commission factor (`loyer = montant HT × coefficient / 100`).

## Milestone Summary

**Key Decisions:**

- **Partner-type formula exception** — Agent/Commercial drop the commission factor; first
  approved break in the frozen-formula constraint, strictly scoped (Rationale: real commercial
  need; `Partenaire` formula + tranches stay frozen).
- **Commission as structural absence, not conditional hiding** — Agent/Commercial UI omits the
  commission row entirely rather than CSS-hiding it (Rationale: defense-in-depth against leakage;
  enforced by the 19-gate grep suite).
- **`partner_type` + `commission_applied` in `params_snapshot`** — PDFs stay reproducible even
  after a partner's type changes (Rationale: immutability invariant from v1.1).
- **View toggle is session-only, server-derived authz** — nav keyed on server `isAdmin`, never on
  the forgeable view flag (Rationale: VIEW-04 — convenience, not a permission change).
- **PDF-scoped number sanitizer** — U+202F/U+00A0 fix lives in the PDF render path; `format.ts`
  untouched (Rationale: don't perturb the byte-determinism surface beyond the PDF layer).
- **Teal rebrand descoped 2026-05-30** — `--gd` token split + WCAG re-audit across ~63 sites was
  too much effort for too little value; shelved, not killed.
