<decision_record>
## The optimistic update is applied, then rolled back — it is not gated on the action

33-UI-SPEC § "The write is one deliberate mutation" specifies `setColumns` called immediately
alongside the action, not on its resolution, with a rollback to the prior `value` on failure.
Concretely that means `PipelineBoard` holds the grouped board in local state seeded from its
`initial` prop, and `onMove` does: capture `previous = columns`; compute and `setColumns(next)`;
`await advanceRelationshipStageAction(...)`; on rejection `setColumns(previous)` and
`toast.error(t('pipeline.toast.error', lang))`. No success toast — the card's new position is the
confirmation, and the codebase does not stack redundant feedback (contrast the dialogs in plan
33-06, where a toast is the only feedback because the modal has already closed).

## `router.refresh()` is called after a successful move, not instead of the optimistic update

`advanceRelationshipStageAction` calls `revalidatePath('/pipeline')` server-side, but the board's
local state is what the user is looking at. Call `router.refresh()` after a successful move so the
server-rendered `initial` prop and the local state reconverge; a `useEffect` reseeds local state
when `initial` changes identity. Without this, a stale board survives any concurrent change.

## The mobile picker is a `Select`, and the reserved options are `disabled`, not hidden

33-UI-SPEC is explicit: the two reserved stages render as disabled options suffixed "(réservé)" so a
partner can see they exist without being able to select them. Hiding them would make the vocabulary
look like five stages, which is precisely the misreading PIPE-02 exists to prevent. `disabled` on a
`SelectItem` is a UI affordance only — the server-side allowlist in plan 33-04's
`advanceStageSchema` is what actually refuses the value.

## `Collapsible`, not `Accordion`

`src/components/ui/accordion.tsx` does not exist in this repo; `collapsible.tsx` does (exporting
`Collapsible`, `CollapsibleTrigger`, `CollapsibleContent`). Both the `Perdu` lane disclosure on the
board and every stage section in the mobile list compose `Collapsible`. Do not run `shadcn add
accordion` — a new registry pull is outside this phase's Registry Safety contract.
</decision_record>
