# Phase 31.1 Plan 06: Sidebar Chrome — Chevron Deletion, Centring, Proportion Summary

## Accomplishments

- `AppSidebar.tsx`: deleted the hand-rolled chevron `<button>`, the `toggleSidebar` destructure, and the `ChevronLeftIcon`/`ChevronRightIcon` imports. Confirmed first (per the plan's read_first) that the rail-insufficiency reasoning the deleted comment carried (SidebarRail's `tabIndex={-1}` + hardcoded English label) had already landed next to Topbar's `SidebarTrigger` in Plan 31.1-03 — nothing was lost.
- Collapsed rail rebuilt: the header wrapper drops `flex-col` (nothing left to stack) and gains `justify-center` when collapsed; the mark renders inside a `size-8 rounded-[9px] bg-sidebar-accent` badge holding an 18×18 glyph — Colibris's measured structure, with the fill deliberately **not** `bg-sidebar-primary` (which resolves to the mark's own `#01CC72`, i.e. invisible-on-invisible).
- Nav icon centring: the `SidebarMenuButton` call site gained `group-data-[collapsible=icon]:mx-auto`, landing each fixed 32px collapsed icon on the same 34px axis as the header badge — by construction, not a pixel offset (D-09).
- `BrandLogo width={190}` → `width={120}` (D-10); `SidebarHeader`'s `p-3` was deliberately left unchanged (Correction 2 — the centring fix makes normalising it unnecessary and out of scope).
- `Shell.tsx`: `SidebarProvider`'s inline `style` values changed `260px`/`72px` → `252px`/`68px` (D-11); the mechanism (inline style beats an arbitrary-property className) and its comment are untouched, only reworded to avoid a self-tripping literal-string match against this plan's own acceptance gate.
- `AppSidebar.tsx`'s `SidebarGroupLabel` gained `text-[11px] uppercase tracking-[0.55px]` (D-12); the nav stays one group, item set and order untouched.
- `AppSidebar.test.tsx`: deleted the two chevron-label assertions (coverage moved to `Topbar.test.tsx`), switched the collapse-toggling tests from clicking the deleted button to `SidebarProvider`'s own Cmd/Ctrl+B shortcut, and added 5 new cases covering the badge structure, the centring classes, the 120px lockup, and the eyebrow styling.
- `tests/container-radius.test.ts`: added `AppSidebar.tsx` to the documented control-detail allow-list for the new `rounded-[9px]` badge radius — see Deviations.
