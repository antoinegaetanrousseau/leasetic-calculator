<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `[adminSegment]` URL → admin tree | a guessed segment must not confirm the tree exists |
| company id / relationship id path segments → admin queries | ids supplied by the caller |
| admin oversight view → contact data | the one place a non-owner legitimately sees relationship metadata |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-08-01 | Information Disclosure | non-admin reaching the companies tree | mitigate | The `[adminSegment]` layout performs the segment check then `requireAdmin()`, both ending in `notFound()` not 403 (D-18/AUTH-14); each page additionally calls `requireAdmin()` as defense in depth (AUTH-15) |
| T-30-08-02 | Information Disclosure | contact rows on the company oversight view | mitigate | `CompanyRelationsTable` renders counts only; grep-gated against `listContactsForRelationship` and any `contact.name`/`.email`/`.phone` reference on both company-view files (CRM-04) |
| T-30-08-03 | Elevation of Privilege | admin surface reused by a partner via shared component | mitigate | The admin relationship detail imports nothing from `app/(authed)/clients/`; grep-gated. Sharing a component would invite a role branch, which is the failure mode this separation avoids |
| T-30-08-04 | Tampering | mismatched company/relationship id pair | mitigate | The relationship detail asserts `relationship.companyId === params.id` and `notFound()`s on mismatch, so a crafted URL cannot render one company's header over another's relationship |
| T-30-08-05 | Information Disclosure | commission envelope (ADMIN-09) | mitigate | New columns are company name, SIREN, holder, owner type, dates and counts — none carries commission signal; grep-gated against `params_snapshot`/`global_params`/`commission` in the companies tree |
| T-30-08-06 | Elevation of Privilege | admin mutating a partner's contacts | mitigate | No mutation control is rendered on the admin tree and the contact actions are gated by `requireRelationshipHolder()` (which refuses admins), so there is no admin write path to another user's contacts in this phase |
| T-30-08-07 | Information Disclosure | search-engine indexing of admin URLs | mitigate | Every page exports `robots: { index: false, follow: false }`, matching the existing admin pages |
| T-30-08-SC | Tampering | npm/pip/cargo installs | mitigate | No package install; every primitive used is already vendored |
</threat_model>
