    matches `t()`'s own FR fallback. Putting the helper here rather than duplicating three lines into
    each vendored file keeps the vendored diff to one import plus one call, which is what makes the
    D-38-11 re-import row cheap to re-apply.

Mitigated by `tests/dialog-close-label.test.ts` plus the two re-import rows — Task 2's entire purpose. |

It carries no user data and is already visible in page source. The value is never echoed back — it only selects between two compile-time constants (`Fermer` / `Close`), so no user-controlled string can reach the accessible name. |

Stated explicitly rather than padded with invented threats. |
| T-38-SC | Tampering | npm installs | accept | This plan installs nothing — `package.json` and `package-lock.json` are untouched, so the package-legitimacy gate does not apply. Acceptance criteria include no install step. |
