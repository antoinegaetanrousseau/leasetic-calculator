the auditor and takes custody of the output.

code — an executor subagent cannot invoke it. Task 2 is a blocking human-action checkpoint where
the operator runs the command in the main session.

progress-table row and its `Complete (retro-documented, outside workflow)` flag must exist before
the auditor reads the roadmap. Without the flag, the audit reads Phase 28 as a v1.6 phase that lost
its PLAN and VERIFICATION files and reports a false gap this phase would then have to dispose of.

input to plan 40-05's `Known gaps at close` section (D-40-02), so it must complete before the
MILESTONES.md entry is written.
