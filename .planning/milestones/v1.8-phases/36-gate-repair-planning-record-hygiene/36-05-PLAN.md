<objective>
Run the sentinel probe once, for real, and capture its output as a credential-free transcript
that Phase 29's artifacts can cite (CLOSE-05, part 2 of 3).

Purpose: this is the whole point of CLOSE-05. Everything Phase 29 could prove statically it
already proved — endpoint separation, a fail-closed guard, Neon's documented copy-on-write
architecture. What it could not prove is that a row written against the `development` branch
is genuinely unreachable from `main`. Phase 35's lesson: a mocked test proves a `WHERE` clause
was composed, never that it filters. This run is the filter.

Output: `36-PROBE-TRANSCRIPT.md` in the phase directory, carrying the invocation form, the
observed output and the verdict — with hostnames only, no credentials.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator shell → Neon `main` (production) | The production connection string crosses into a process on a developer machine. This is the boundary INFRA-05 exists to police. |
| operator shell → agent chat transcript | Whatever the operator pastes becomes part of a durable conversation log and, via Task 2, a git-tracked planning artifact. |
| agent → production credentials | Deliberately closed: the agent never receives, requests, echoes or stores either URL. |
