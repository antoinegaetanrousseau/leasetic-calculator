## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-03-E | Elevation of Privilege | adminUpdatePartnerType endpoint | mitigate | **HIGH** — only admins may change partner_type; a partner flipping their own type to Agent/Commercial would flip their proposals commission-free. `requireAdmin()` runs as the FIRST statement; the field is also `input:false` in Better Auth (Plan 22-01) so there is no self-service mutation path. |
| T-22-03-R | Repudiation | type change without trail | mitigate | writeAuditLog records actorId + before/after specific type on every change (PTYPE-03); no-op changes are skipped, real changes always audited. |
| T-22-03-I | Information disclosure | commission leakage via list/form HTML | mitigate | partner_type is an enum, not a rate; no commission projection added to partners.ts; grep-contract gates (Plan 22-05) assert zero `commission_pct`/`_pct` on the list, form, and row-action surfaces. |
| T-22-03-T | Tampering | client posting an invalid type | mitigate | Server-side `createPartnerFormSchema.parse` + the action's narrowed `newType` union + the DB CHECK constraint (Plan 22-01) all reject out-of-enum values. |
| T-22-03-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; nothing to audit. |
</threat_model>
