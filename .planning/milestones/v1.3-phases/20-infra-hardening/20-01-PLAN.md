<objective>
INFRA-03 — Harden Better Auth against cross-origin requests by replacing the
current minimal `trustedOrigins` stub at `src/lib/auth/index.ts:173` with a
production list derived from existing env vars + a Vercel-preview wildcard, and
prove the derivation with a Vitest unit test. Per D-09 (Better Auth config is the
single source of truth), D-11 (proxy.ts is NOT touched), and D-13 (no new env
vars — derive from APP_URL + NEXT_PUBLIC_APP_URL + RESEARCH §1 wildcard).

Purpose: Phase 6 follow-up #2 surfaced that Better Auth's CSRF default still
admitted requests with a forged Origin header (HTTP 200 + valid session). The
project currently relies on `SameSite=Lax` + `__Secure-` cookie discipline
alone. This plan adds the documented `trustedOrigins` enforcement layer that the
ROADMAP Phase 20 success criterion #3 calls for.

Output:
- `src/lib/auth/index.ts` with a full `trustedOrigins` list inside the
  `betterAuth({})` config block (replaces the line-173 stub).
- `src/lib/auth/trusted-origins.test.ts` with 6 unit tests covering each
  derivation branch (APP_URL set, NEXT_PUBLIC_APP_URL set, wildcard always
  present, localhost always present, VERCEL_URL fallback via resolveBaseUrl,
  no undefined falsy strings leak through).

This is Wave 1 (parallel with 20-02). Autonomous — no user interaction.
</objective>

|----------|-------------|
| browser → Better Auth API | Cross-origin requests to `/api/auth/*` mutation endpoints; the trustedOrigins gate is the new defense layer added here. |
| Vercel preview deploys → Better Auth API | Preview URLs with dynamic subdomains (`leasetic-matrice-git-pr-NNN-team.vercel.app`); must be allowed without per-deploy env-var churn. |
| local dev → Better Auth API | `http://localhost:3000` cookie flows in development; must remain trusted. |

Better Auth rejects requests whose Origin is not in the list with a non-2xx response. Test 6 covers the VERCEL_URL fallback path through baseURL. |
| T-20-01-02 | Spoofing | Vercel preview deploys with dynamic subdomains | medium | mitigate | The literal wildcard `https://leasetic-matrice-*.vercel.app` covers every preview URL the Vercel project produces without runtime env-var computation.
