## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-03-01 | Information disclosure (status enum injection) | partners.ts query | mitigate | searchParams.status validated against enum ('active'|'invited'|'inactive') before passing to query; invalid values → undefined (no filter) → safe default behavior |
| T-18-03-02 | SQL injection via q (search) | listPartnersWithLastActivity ILIKE | mitigate | Drizzle parametric binding (`ilike(users.email, \`%${q}%\`)`) safe; never string-concatenate q into raw SQL |
| T-18-03-03 | IDOR via Voir les propositions | PartnerRowActions href | mitigate | Action only renders inside admin-gated route (requireAdmin in /partners SSR); the href targets /proposals which has its own admin-role gate per Plan 18-01 (T-18-01-01 mitigation) |
| T-18-03-04 | Information disclosure (deleted users in list) | listPartnersWithLastActivity | mitigate | WHERE users.deletedAt IS NULL clause in every branch (Test 7 enforces) |
